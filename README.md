# Literature_card_game_simulation_based_analysis
To analyze increase in complexity with number of players.

# Dependencies
- Rust

# Installation and Usage
```
git clone https://github.com/Vizkid04/Literature_card_game_simulation_based_analysis.git
cd Literature_card_game_simulation_based_analysis
cargo build --release
./target/release/literature_benchmark
```
You should see svg plots generated inside the parent directory "Literature_card_game_simulation_based_analysis", and outputs of the code-run in the terminal.
